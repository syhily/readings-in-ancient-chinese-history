# OCR 校对与 Markdown 规范

## 一、书籍与页码换算

《中国古代史读本》（上下册合订扫描，PDF 共 998 页），陈苏镇、张帆编，
北京大学出版社 2006 年 1 月第 1 版，ISBN 7-301-09104-4
（大学历史学论文读本系列，郭双林总策划）。

PDF 内部结构：

| PDF 页 | 内容 |
|--------|------|
| 1–4 | 上册封面、书名页、版权页 |
| 5 | 总序（郭双林，原书罗马页码 I 起） |
| 6–7 | 总目录 |
| 8–9 | 上册扉页、空白 |
| 10–515 | 上册正文（原书 3–508）→ **PDF = 原书 + 7** |
| 516–519 | 下册封面×2、扉页、下册目录 |
| 520–998 | 下册正文（原书 511–989）→ **PDF = 原书 + 9** |

渲染原页核对：

```sh
gs -dNOPAUSE -dBATCH -sDEVICE=jpeg -r150 -dFirstPage=N -dLastPage=M \
   -sOutputFile=ocr/pages-probe/前缀-%d.jpg "source/中国古代史读本(上下).pdf"
```

注意 gs 输出文件从 1 重新编号（`前缀-1.jpg` 即第 N 页）；每次调用的输出
前缀必须唯一，否则互相覆盖。疑难字用 `-r300`。

## 二、多模式交叉校对

`make ocr` 跑两种模式（`mineru-open-api extract`，200 页/片自动分片，
断点续跑；token 在 `~/.mineru/config.yaml`）：

| 模式 | 特点 | 用途 |
|------|------|------|
| `pipeline` | 无幻觉，逐字可靠 | **校对基准** |
| `vlm` | 复杂版式精度更高，偶有幻觉 | 交叉比对 |

校对方法：

1. 以 `ocr/pipeline/` 结果为底稿；vlm 取对应段，`diff -u` 逐处审查；
2. 分歧渲染原页裁决，不凭语感猜；
3. 若需对个别疑难页第三次识别，可用 `--pages N-M` 单页重跑某一模式。

### 本书注释形态（与诗词书/散文书不同，重点）

原书注释是**篇末编号注**（〔1〕〔2〕…，排在正文之后、「参考论著」之前），
不是页底圈码脚注。处理为 pandoc **行内脚注**：

1. 正文中的〔N〕标记处改为 `^[……]`，注文从篇末注释区搬入；
2. 注释编号必须逐篇核对连续（〔1〕到〔N〕不重不漏），OCR 常把〔〕
   识别为 []、【】或丢号；
3. 搬完后删除篇末注释区原文；EPUB 中脚注由 pandoc 自动收集在各篇
   （`##` 拆分出的 xhtml）末尾，位置与原书篇末注基本一致。

MinerU 系统性漏收/误识，校对时都要对照原书目录与渲染页核查：

- 篇内小节序号标题（「一」「二」等，可能独立成行也可能在段首）；
- 个别篇标题、跨页断段（含 part 分片边界处的段落）；
- 篇首导读页的导读与作者介绍（楷体块，OCR 可能并入正文或丢失）；
- 篇末「（选自……）」出处行与「参考论著」书目；
- 高频字形坑：人/入混淆、书名号缺漏、破折号丢失、引文被误标为
  `##` 标题（还原为块引用）；
- vlm 幻觉典型形态：`◆ ◆ ◆`/`● ● ●` 点行多为原书省略号行「……」。

原书自身误植**照录不擅改**，加 `<!-- 疑：原书作「x」 -->`。

删除杂质：页眉（偶数页「页码 作者名」、奇数页「篇名 页码」）、页码、
书脊文字、`![](images/…)`；合并跨页断段。

## 三、章节切分与标题约定

`manuscript/` 下每篇一个文件，两位序号前缀保证顺序：

```
manuscript/00-frontmatter.md     # 电子版说明与免责声明（不进目录）
manuscript/01-preface.md         # 总序（郭双林）
manuscript/05-volume-1.md        # 上册扉页（只含 # 上册）
manuscript/10-….md               # 上册各篇
manuscript/55-volume-2.md        # 下册扉页（只含 # 下册）
manuscript/60-….md               # 下册各篇
```

标题层级：

- `#`：总序、上册、下册（对应原书目录层级）
- `##`：各篇选文标题，作者名以 `[作者]{.zuozhe}` 行内 span 附后
  （如 `## 殷周制度论[王国维]{.zuozhe}`，作者楷体小一号）；上下册编后记
  同用 `##`（如 `## （上册）编后记[陈苏镇]{.zuozhe}`）
- `####` 及更深：篇内小节标题（原书的「一」「二」等序号节），**不进目录**

pandoc `--split-level=2` 把每个 `##` 拆成独立 xhtml（即每篇硬分页），
脚注自动收集在篇末。

## 四、篇首导读页（本书特化）

原书每篇开头是独立导读页：左上作者名（黑体）、居中篇名，下接**楷体**的
选文导读一段与作者介绍一段，正文次页另起。Markdown 写法：

```markdown
## 殷周制度论[王国维]{.zuozhe}

::: {.daodu}
殷周之际，文物制度发生了巨大变革。……（导读，楷体）

王国维（1877—1927），浙江海宁人，……（作者介绍）
:::

\newpage

中国政治与文化变革，莫剧于殷周之际。……（正文）
```

`\newpage` 独占一行，由 `scripts/newpage.lua` 转为文件级硬分页，
导读页与正文分开，对应原书版式。

## 五、篇末结构（本书特化）

每篇末尾依次是：正文 → 出处行 → 参考论著（注释由 pandoc 自动收在篇末，
无需手写注释区）：

```markdown
[（选自余英时：《论戴震与章学诚》，三联书店，2000 年）]{.chuchu}

#### 参考论著 {.cankao}

1. 钱穆：《中国近三百年学术史》，商务印书馆，1997。第一章《引论》。
2. ……
```

- 出处行：原书居中、小字，用 `[…]{.chuchu}`（无出处行的篇目省略）；
- 参考论著：原书为饰花居中标题，EPUB 从简为居中黑体
  （`#### 参考论著 {.cankao}`，不进目录），书目用有序列表
  （pandoc 原生 `<ol start="N">`），文献信息中的半角括号
  （如 `2003(3)`）照原书保留。

## 六、引文与诗体

- 行文中的段落式引文（史书、论文摘引）：块引用 `> `（楷体缩进）；
- 需逐行换行但换行不是分段的引文：块引用内嵌行块 `> | `；
- 诗体引文（《诗经》、诗词、韵文，每句一行）：裸行块 `| `，左缩进；
- 本书无居中诗块约定，`::: {.poem}` 一般不用。

## 七、古文字形（甲骨文/金文等，本书特化）

原书个别文章（如郭沫若《奴隶制时代》，PDF 23–60）在行内插入甲骨文、
金文等无法编码的古文字形（如「仆墉土田」之墉的金文、「古文敦字」）。
这些字形一律做成行内 SVG 图片，不用 Unicode 近似字代替，也不用位图。

制作流程（需要 ghostscript、ImageMagick、potrace）：

```sh
scripts/glyph.sh <PDF页码> <x> <y> <宽> <高> <输出名>
# 产物：assets/glyphs/<输出名>.svg（入库）；600dpi 整页渲染缓存于
# ocr/glyph-src/page-NNNN.png（不入库，可复用）
```

坐标定位：先 `-r150` 渲染整页找到字形大致位置（150dpi 坐标 × 4 = 600dpi
坐标），再对 600dpi 缓存图用区域查看微调裁切框，以字形完整、不带邻字
残笔为准。裁切后 potrace 矢量化，SVG 只保留 viewBox，显示尺寸由 CSS
`img.glyph` 控制（行内高 1.05em，随文排）。

Markdown 行内引用（alt 文字写字形释读，供读屏与检索）：

```markdown
……有“仆![墉](assets/glyphs/yong.svg){.glyph}土田”，可见这是一个成语。……
```

已制作的字形：

| 文件 | 释读 | 出处 |
|------|------|------|
| `assets/glyphs/yong.svg` | 墉（金文，《召伯虎簋》「仆墉土田」） | 原书 25（PDF 32） |
| `assets/glyphs/yong-alt.svg` | 墉（另一写法，「与墉近似」） | 原书 25（PDF 32） |
| `assets/glyphs/dun-guwen.svg` | 敦（古文，「古文敦字作…」） | 原书 25（PDF 32） |

校对时若发现新的古文字形，按同一流程补做并登记到上表。OCR 对这些
字形通常输出乱码或空缺，定位线索是行内的异常空白与乱码字符。

## 八、其他约定

- 括号：正文统一全角（）；脚注/书目的文献信息照原书保留半角；
- 问叹号等其余标点统一全角（原书可能印半角，以统一为准）；
- 行内强调 `**…**` 排黑体，`*…*` 排楷体（中文不倾斜）；书名号《》保留；
- 行块的竖线必须是 ASCII `| `，全角 `｜` 不会被 pandoc 解析；
- 拿不准的字，在行间加 HTML 注释 `<!-- 疑：原书作「x」 -->` 留待复核；
- 强制换页只写 `\newpage`，不要用 CSS `page-break`。

## 九、构建用到的过滤器

- `scripts/newpage.lua`：`\newpage` → 空的 `.unlisted` 二级标题，借助
  `--split-level=2` 的文件拆分实现硬分页；
- `scripts/ascii-heading-ids.lua`：标题锚点改写为 ASCII id（`sec-N`），
  保证各阅读器目录链接可跳转；
- `scripts/chapter-titlepage.lua`：给「第X章」标题加 `.zhang`
  （本书无「第X章」标题，保留不用）；
- `scripts/poem-title.lua` / `poem-stanzas.lua` / `xuanwen-title.lua`：
  诗块与选文标题处理（本书一般不用，保留不用）；
- `scripts/pangu.lua`：盘古之白（中文字符与西文/数字相邻处插入 U+2009）；
- ~~`scripts/fix-nav.py`~~：诗词书专用（目录改写「作者《篇名》」），
  本书标题语序无需改写，**已删除**。

## 十、本书 epub.css 特化点（勿回改）

- 书名页作者后缀由「著」改为「编」（`p.author::after`）；
- `.daodu`：篇首导读与作者介绍楷体块（见「四」）；
- `h4.cankao`：篇末「参考论著」居中黑体标题（见「五」）；
- `.chuchu`：篇末出处行居中小字（见「五」）；
- `img.glyph`：行内古文字形 SVG（覆盖全局 img 块级规则，见「七」）。
